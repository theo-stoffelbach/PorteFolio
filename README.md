# Portfolio

Portfolio personnel de Théo Stoffelbach, développeur fullstack.

## Style

Design inspiré de GitHub avec :
- Palette de couleurs sobre et professionnelle
- Typographie système (San Francisco / Segoe UI)
- Interface épurée et minimaliste
- Animations subtiles

## Structure

- `index.html` - Page principale du portfolio
- `stage.html` - Détails de l'expérience de stage
- `style/` - Feuilles de style CSS
  - `style.css` - Styles principaux
  - `projectMainPage.css` - Styles des projets
  - `experience.css` - Styles des expériences
- `img/` - Images et icônes

## Technologies

HTML5, CSS3

## Déploiement

Ouvrir `index.html` dans un navigateur web.
